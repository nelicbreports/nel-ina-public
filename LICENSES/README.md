# Licensing scope map

This repository uses dual licensing:

- **MIT License** (`/LICENSE`) for software and code.
- **Open Government Licence v3.0** (`/LICENSES/OGL-3.0.txt`) for report narrative and non-code report assets.

## MIT scope (default for code and configuration)

Unless explicitly stated otherwise, the following are licensed under MIT:

- Repository source/configuration files.
- Styling and technical implementation files (for example `docs/assets/NHS_report_theme.css`).
- Supporting project files used to build and maintain report outputs.

## OGL v3.0 scope (report narrative and non-code assets)

The following are licensed under OGL v3.0:

- Report narrative/content in `docs/index.html`.
- Report figures, tables, images, and other non-code report assets (including assets described in `docs/assets/README.md`).
- Generated report output where content is public sector information.

## Attribution requirements for OGL content

Where no provider-specific attribution is supplied, use this default attribution text:

> Contains public sector information licensed under the Open Government Licence v3.0.
